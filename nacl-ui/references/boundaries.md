# 范围与边界

## 本 Skill 能做什么

- 从固定 starter 生成 A/B/D 工程（两套布局）。
- 通过 JSON 做 L1 主题和 L2 既有组件内的布局/交互定制。
- 确定性校验、mock 预览、独立前端/桌面构建、完整验收。
- 解释注册表能力、校验错误和能力缺口。

## 不能做什么

- **不写或改固定实现**：固定 Vue 组件、渲染器、状态/动作协调、Rust SDK、Tauri IPC、生成的 TypeScript 契约、页面/项目 Schema 都由工程固定。普通 UI 任务只改页面 JSON。
- **不启用 L3**：不能新增 Vue 组件、任意 JavaScript/表达式、原始 HTML、shell/命令名、新数据源或新 IPC 命令。现有组件表达不了时，说明缺口与替代方案，由用户决定是否另开扩展任务。
- **不提供游戏获取**：没有游戏文件、版本清单、下载源、自动安装/修复流程。缺失元数据、客户端或 Java 时只报告原因。
- **不操作真实账号**：默认不执行真实 Microsoft 登录/权益/启动。A/D 的真实在线分支需要明确授权和环境。
- **不冒充证据**：Mock 必须显著标注，只证明页面/适配器链路；自有 Java 探针不是 Minecraft；构建成功不等于真实桌面行为或真实游戏通过。
- **不改变模式语义**：不通过隐藏按钮、改 feature、改 Schema 或改身份组件来绕过 A/B/D 能力隔离。
- **不降低验收**：修复问题时保留类型检查、Schema/语义校验、Rust 检查和安全边界；不删除核心组件或测试来让报表变绿。

## Provider / SDK 开发

第三方 Provider、账号 Provider、加载器 Adapter、安装执行器扩展属于显式扩展任务，不属于普通 UI Skill 默认流程。它们需要公开契约评审、独立消费工程和相应测试；不要让普通 UI 任务顺带重写 SDK/IPC。

## 生成工程保留的声明

生成工程保留固定 SDK Git 来源与契约、模板代码、锁文件和分发的许可/第三方声明。用户新增内容可另行选择许可，但不能移除所复用部分的声明。真实发布前的权属、第三方许可和隐私检查不属于本 Skill 的默认动作。

## 证据分级

| 级别 | 能证明 | 不能证明 |
| --- | --- | --- |
| 配置校验 | 页面/项目结构与注册表一致 | 运行时行为、后端能力 |
| 单元/回归测试 | 固定代码路径在注入适配器下的行为 | 真实 IPC/账号/文件/进程 |
| 独立构建 | 工程可编译、可产出 EXE/dist | 窗口交互与任务结果 |
| 真实桌面 IPC | 本机后端命令、任务事件、文件/进程行为 | 真实 Microsoft 权益或真实 Minecraft |
| 真实账号/游戏 | 对应真实环境结果 | 其他模式/分支 |

报告时按级别分开写，不能互相替代。
