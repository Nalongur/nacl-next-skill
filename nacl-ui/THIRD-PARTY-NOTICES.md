# 第三方声明

生成工程使用 Cargo 和 npm 下载的第三方依赖，各依赖适用其自身许可。锁文件记录版本和来源；完整 Skill 仓库中的 `third-party/index.json` 收集了锁文件条目和本地可取得的许可、NOTICE 原文。

页面校验器由 Ajv 生成，包含 Ajv 生成的代码；Ajv 采用 MIT 许可，许可原文见 `third-party/index.json` 的 ajv 条目。应用图标源自 [NaCL Next 网站 favicon](https://nacl-next.onrender.com/favicon.svg)。
